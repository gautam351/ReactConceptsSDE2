# React Lazy Loading Example

This project demonstrates how to implement different concepts in a React application using which are required to be an SDE 2.

---

## Features

1. Lazy Loading : Done 
- **Lazy Loading**: Dynamically load components only when required.
- **Suspense Fallback**: Display a loading indicator while the component is being loaded.
- **Interactive UI**: Load a child component on button click.
